## 📋 Project Overview

Personalized Healthcare & Medicine Recommendation System to:
1. **Predict diseases** from patient-reported symptoms (132 possible symptoms → 41 disease classes)
2. **Recommend medications**, precautions, diet plans, and workout regimens
3. **Suggest similar medicines** using content-based filtering (TF-IDF + Cosine Similarity)

## 🚀 Quick Start

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Train Models (Run Notebook)
Open and run the Jupyter notebook to train all ML models and save `.pkl` files:
```bash
jupyter notebook notebooks/Personalized_Healthcare_Recommendation_System.ipynb
```
Run **all cells** from top to bottom. This will:
- Train SVC, Random Forest, Gradient Boosting, KNN, and Naive Bayes models
- Save trained models to `models/` directory
- Generate `dataset/medicine.csv` and `models/similarity.pkl`

### Step 3: Start Flask App
```bash
python app.py
```

### Step 4: Open Browser
Navigate to: **[http://localhost:5000](https://personalized-healthcare-medicine-ewf5.onrender.com)**

## 📊 Dataset Information

- **Training.csv**: 4,920 rows × 133 columns
- **Features**: 132 binary symptom columns (0/1)
- **Target**: `prognosis` column (41 disease classes)
- **Missing values**: 0
- **Class balance**: ~120 records per disease (highly balanced)

## 🧠 Recommendation Engine Architecture

```
Patient Symptoms Input
         ↓
  Symptom → Feature Vector (132-dim binary)
         ↓
  SVC Linear Kernel → Disease Prediction
         ↓
  ┌──────────────────────────────────┐
  │  Disease → Recommendations Lookup│
  │  ├── Description                 │
  │  ├── Medications (CSV lookup)    │
  │  ├── Precautions (CSV lookup)    │
  │  ├── Diets (CSV lookup)          │
  │  └── Workout (CSV lookup)        │
  └──────────────────────────────────┘
         ↓
  Content-Based Medicine Recommendation
  (TF-IDF + Cosine Similarity on Drug DB)
